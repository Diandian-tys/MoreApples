# More Apples / 更多苹果

**A Minecraft Bedrock Edition Add-on**

This add-on adds **62 unique apples** with different colors and effects to your world.  
Some give positive buffs, some give negative effects, and some are mixed for fun and risk.

这是一个 Minecraft 基岩版附加包，在你的世界中添加了 **62 种** 特性不一样的苹果。  
有的提供正面效果，有的带来负面效果，有的则好坏参半。

---

## Features / 功能

- 62 brand-new apples (no vanilla red / golden / enchanted golden apple)
- Dedicated creative inventory group: **More Apples / 更多苹果**
- Mix of positive, negative and mixed effects
- Custom colored textures for each apple
- Fully translated (English + 简体中文)

---

## Installation / 安装

1. Download the `.mcaddon` (or the BP + RP folders)
2. Double-click or import into Minecraft
3. Create / Edit a world → **Behavior Packs** and **Resource Packs** → activate both
4. (Recommended) Enable any required experiments if prompted

---

## Notes / 注意事项

- All apples are edible and stack to 64.
- Effects use vanilla potion effects.
- Textures are simple procedural colored apples (you can replace them with better art later).
- Compatible with most other add-ons.
